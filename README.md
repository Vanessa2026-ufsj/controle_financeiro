Sobre o projeto
O projeto tem como proposta apoiar a organização e o acompanhamento das finanças, reunindo informações financeiras em uma aplicação web. Este README registra as informações que foi possível confirmar sobre a publicação. Como o conteúdo interno da aplicação não ficou disponível para inspeção automatizada, os recursos específicos e a arquitetura técnica precisam ser validados no projeto-fonte antes de serem documentados como funcionalidades existentes.
Objetivo
Oferecer uma interface digital para apoiar o controle financeiro e facilitar a consulta das informações necessárias ao acompanhamento do orçamento.
Funcionalidades
A confirmar na versão atual do sistema. Mantenha nesta seção apenas os recursos que estejam implementados e testados.

- [ ] Cadastro, consulta, edição e exclusão de lançamentos financeiros
- [ ] Registro de receitas e despesas
- [ ] Classificação por categorias
- [ ] Filtros por mês, ano ou período
- [ ] Resumo mensal e saldo
- [ ] Gráficos e indicadores financeiros
- [ ] Relatórios e exportação de dados
- [ ] Autenticação e separação de dados por usuário
